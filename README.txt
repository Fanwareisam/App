MY CREATIONS - ANDROID PROJECT

NOTE: renaming a .zip to .apk does NOT work. An APK must be compiled and signed.
This project is complete; you only need to build it (pick ONE way):

A) PHONE ONLY (free, GitHub):
   1. Create a GitHub account + new repository.
   2. Upload ALL files from this folder (keep the .github folder).
   3. Open the repo > Actions tab > "Build APK" > wait ~3 min.
   4. Open the finished run > Artifacts > MyCreations-apk > download, unzip, install app-debug.apk.

B) ANDROID STUDIO (PC): File > Open this folder > Build > Build APK(s).
   APK appears in app/build/outputs/apk/debug/app-debug.apk

Works on Android 10 and newer. "Download ZIP" saves to your Downloads folder.
